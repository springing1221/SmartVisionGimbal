# SmartVisionGimbal

基于安路 FPGA 的实时数字图像处理与视觉跟踪系统。

## 项目简介

本项目以 HX1P35A 开发板为核心，目标器件为 PH1P35MDG324，结合 SC520 摄像头、HDMI 显示器和双轴舵机云台，实现视频采集、图像处理、视觉识别及机电控制。

系统主要包含三个功能方向：

1. **多算法图像处理**：支持多种图像显示与处理模式，并集成自动曝光（AE）和自动白平衡（AWB）相关功能。
2. **颜色、形状与手势识别**：支持红、绿、蓝、黄颜色分类，圆形、三角形、矩形识别及指定目标跟踪；支持手部定位和 0～9 数字手势识别。
3. **人物运动目标检测与云台跟拍**：通过运动目标检测获取目标位置，生成双路 PWM 控制信号驱动双轴舵机云台。

三个功能模块采用互斥模式运行，共享视频采集、DDR2 缓存及 HDMI 显示等公共资源。舵机由独立电源供电，FPGA 控制端与舵机驱动端共地。

## 硬件组成

- FPGA 开发板：HX1P35A（PH1P35MDG324）
- 摄像头：SC520
- 视频接口：MIPI 输入、HDMI 输出
- 图像显示：HDMI 显示器
- 执行机构：双轴舵机云台（轮趣 SC20F）
- 舵机供电：12 V 电池经降压模块转换为 5 V 独立供电

`project/td_project/SmartVisionGimbal.al`

## 打开工程

1. 下载并解压完整工程包。
2. 使用安路 FPGA 对应开发工具打开 `project/td_project/SmartVisionGimbal.al`。
3. 检查工程文件引用路径及本机已安装的器件库、IP 资源和工具版本。
4. 根据实际开发板连接摄像头、HDMI 显示器及云台控制接口。

> 注意：工程中包含与安路器件及 IP 相关的配置/生成文件。不同开发环境下可能需要安装匹配版本的器件库和 IP 组件。请以本项目实际硬件及工具环境为准。
